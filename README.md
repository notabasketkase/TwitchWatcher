# TwitchWatcher

A simple Windows desktop app that watches Twitch for your favourite streamers,
notifies you when they go live (or when Drops are active), and can automatically
open their channel in your browser.

## Features

- Watch a list of streamers, organised into groups
- Desktop notifications when a streamer goes live
- Auto-open live channels in your browser
- **Drops Only** mode — only alert/open when a streamer has "drops" in their title
- A **Drops Games** watch list for spotting drop campaigns
- Credentials stored securely — your Client Secret lives in Windows Credential
  Manager (the same encrypted vault your browser uses), never in a file

## Setup

You'll need a free Twitch API Client ID and Client Secret. See the included
**TwitchWatcher_Setup_Guide.pdf** for step-by-step instructions — it takes about
five minutes and you only do it once.

## Privacy

TwitchWatcher only talks to Twitch's official API (`id.twitch.tv` and
`api.twitch.tv`). No data is collected and nothing is sent to any third party.
